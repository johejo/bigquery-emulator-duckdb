# The SQL features tools/restprobe checks, which generate docs/sql.md.
#
#   setup SQL             A statement run on every fresh emulator before a query, in project `test`.
#   section TITLE         Starts a table in the report.
#   query NAME | SQL      A query for the feature NAME, run with `test.d` as the default dataset.
#                         Repeat it to probe several forms of one feature.
#   note NAME | TEXT      What a probe cannot observe, in a sentence or a link to a section of
#                         docs/compatibility.md, which holds the details.
#
# Every query must be valid GoogleSQL against the fixture; the probe fails on one that is not.
# List only forms BigQuery accepts: those it documents, and undocumented ones that BigQuery's
# answers to unverified cases show it runs. Leave out GoogleSQL syntax that BigQuery rejects.
