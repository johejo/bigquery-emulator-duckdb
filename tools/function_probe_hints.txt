# Hints for //:function_probe, which reads them when it runs, so changing them needs no rebuild.
#
#   query NAME SQL                     probes SQL instead of the calls generated from the
#                                      function's signatures; repeat it to cover each signature
#                                      BigQuery documents
#   note NAME TEXT                     shows TEXT in the Notes column, for a limit the probe's
#                                      calls do not show; at most one per function
#   sample TYPE | LITERAL              calls an argument of TYPE with LITERAL; an ARRAY or STRUCT
#                                      without a sample of its own is built from its elements' or
#                                      fields' samples
#   optional TYPE | LITERAL            the same, for an optional argument in the longest form
#   longest PATTERN                    also probes the longest form of the signatures PATTERN
#                                      matches, with every positional optional argument
#   values SET | LITERAL | LITERAL...  names a set of values for `elements`
#   elements PATTERN | SET [| TYPE]    calls the signatures PATTERN matches once for each value in
#                                      SET, as <T1>, an array of <T1>, a RANGE from it, and ANY TYPE;
#                                      with TYPE, replaces arguments of that concrete type instead
#   argument PATTERN | TYPE | LITERAL  calls an argument of TYPE with LITERAL in the signatures
#                                      PATTERN matches, where a type does not describe valid values
#
# NAME must be in tools/bigquery_functions.txt. TYPE and PATTERN refer to signatures as
# `--signatures` prints them, such as `RANGE_BUCKET(<T1>, <array<T1>>) -> INT64`, which shows each
# signature with its call:
# `bazel run //:function_probe -- --signatures $PWD/tools/bigquery_functions.txt $PWD/tools/function_probe_hints.txt`
# TYPE is an argument's type without its cardinality and name, and PATTERN is an ECMAScript
# regular expression that has to match some signature. Where several `elements` or `argument`
# hints match, the last one applies.
