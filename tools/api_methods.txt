# The REST API requests tools/restprobe sends, which generate docs/api.md. The methods themselves
# come from third_party/bigquery/discovery.json; a method without requests here is probed with one
# the probe builds from its path.
#
#   file NAME | LINE          Writes LINE to the file NAME in the probe's scratch directory, $DIR.
#   setup METHOD PATH [BODY]  A request sent to every fresh emulator before a probe.
#   request ID | METHOD PATH [BODY]
#                             A request for the method ID, such as bigquery.jobs.query. Repeat it
#                             to probe several forms of one method.
#   note ID | TEXT            What the emulator ignores or does differently from BigQuery.
#
# Paths are below the server root and may carry a query string. Every request here must succeed
# or be rejected as unsupported; the probe fails on one that fails for another reason.
