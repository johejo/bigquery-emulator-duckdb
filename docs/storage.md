# BigQuery Storage API

Generated by `just docs` from `tools/storageprobe`. Probes check execution, not result compatibility.

| RPC | Status | Forms and limitations |
| --- | --- | --- |
| CreateReadSession | Partial | Arrow and Avro snapshots, projection and row restrictions; historical snapshots, sampling, compression and some types unsupported |
| ReadRows | Partial | Arrow and Avro, offsets; per-call serialization options unsupported |
| SplitReadStream | Supported | Disjoint children of the same snapshot |
| CreateWriteStream | Partial | COMMITTED, BUFFERED and PENDING; stream state is process-local |
| AppendRows | Partial | Protobuf rows, default and explicit streams, offsets; Arrow input, defaults, parameterized columns, annotations, schema evolution, JSON and GEOGRAPHY unsupported |
| GetWriteStream | Partial | BASIC and FULL; legacy default streams without table creation metadata unsupported |
| FinalizeWriteStream | Supported | Explicit streams, including repeated finalization |
| FlushRows | Supported | BUFFERED streams with an inclusive offset |
| BatchCommitWriteStreams | Supported | Atomic commit of finalized PENDING streams |
